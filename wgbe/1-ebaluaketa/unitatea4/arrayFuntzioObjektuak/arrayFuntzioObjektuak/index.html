FUNTZIOAK · 05 · ARROW + ARRAY-AK

Funtzioak array-etan.

map(), filter() eta forEach() callback-etarako erabil daitezke. Arrow function-ek kodea laburtzen dute, metodo bakoitzaren helburua aldatu gabe.

05 / 05
Mmap()ERALDATU

Arrow callback-ak elementu bakoitza bikoizten du; emaitza array berri batean jasotzen da.

Emaitza hemen.
Ffilter()AUKERATU

Arrow callback-ak baldintza adierazten du; baldintza betetzen duten elementuak bakarrik geratzen dira.

Emaitza hemen.
↻forEach()EKINTZA BAT ELEMENTU BAKOITZEKO

Arrow callback-ak elementu bakoitzaren izena idazten du. forEach-ek ez du array berririk itzultzen.

Emaitza hemen.
map()Elementu bakoitza eraldatu, array berria sortu
forEach()Ekintza egin elementu bakoitzeko

ARRAY-AK · 02 · JATORRIZKOA ALDATU

Gehitu eta kendu.

Metodo hauek jatorrizko array-a aldatzen dute. Exekutatu adibideak, eta alderatu metodoaren itzulera array-aren azken edukiarekin.

02 / 05
+push()AMAIERAN GEHITU

Gehitu elementu bat edo gehiago amaieran. Itzultzen du: array-aren luzera berria.

Emaitza hemen.
−pop()AMAIERATIK KENDU

Azken elementua kentzen du. Itzultzen du: kendutako elementua.

Emaitza hemen.
↑unshift()HASIERAN GEHITU

Gehitu elementu bat edo gehiago hasieran. Itzultzen du: array-aren luzera berria.

Emaitza hemen.
↓shift()HASIERATIK KENDU

Lehen elementua kentzen du. Itzultzen du: kendutako elementua.

Emaitza hemen.
↔splice()EZABATU · GEHITU · ORDEZKATU

splice(hasiera, ezabatuKopurua, elementua1, ...) array-a aldatzen du, eta ezabatutako elementuak array batean itzultzen ditu.

Emaitza hemen.

ARRAY-AK · 04 · BILATU ETA EGIAZTATU

Bilatu eta egiaztatu.

Lehen elementua edo haren indizea bilatu, elementu bat dagoen egiaztatu, edo baldintza array osoari aplikatu.

04 / 05
Ffind()LEHEN ELEMENTUA

Baldintza betetzen duen lehen elementua itzultzen du; aurkitzen ez badu, undefined.

Emaitza hemen.
#findIndex()LEHEN INDIZEA

Baldintza betetzen duen lehen elementuaren indizea itzultzen du; bestela, -1.

Emaitza hemen.
?includes()BADAGO?

Balio bat array-an dagoen egiaztatzen du; true edo false.

Emaitza hemen.
#indexOf()POSIZIOA

Balioaren lehen indizea itzultzen du; aurkitzen ez badu, -1.

Emaitza hemen.
1+some()BAT BATEK?

Gutxienez elementu batek baldintza betetzen duen aztertzen du.

Emaitza hemen.
✓every()GUZTIEK?

Elementu guztiek baldintza betetzen duten aztertzen du.

Emaitza hemen.
04

find() elementua ematen du; findIndex() / indexOf() posizioa; some() / every() balio boolearra.
